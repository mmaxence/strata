Room to move.

Strata arranges existing interface elements in CSS 3D space. It preserves native inputs, text, links and application state.

What it does

  • Arrange panels as a grid, pile, fan or review rail.
  • Move collections along belt, wave, spiral or floating paths.
  • Focus a panel, drag to rearrange or steer, and return to the surrounding context.
  • Assemble adaptive workspaces with resizing and compact summaries.
  • Respect reduced motion and compact screen layouts.
  • Pause inactive scenes and destroy controllers cleanly.

Explore the examples

  • Interactive playground: Creative workspace, Collection, Fly-through and Explosion.
  • Minimal example: required HTML and structural CSS.
  • Workspace example: assembly, resizing and adaptive detail.
  • Performance: reproducible source sizes and a six-card browser frame benchmark.

The showcase combines the runtime with custom demo choreography, including nested orbit and stack modules, an exploded interface and a rocket passing through glass layers. These compositions are examples, not separate runtime API methods.

Use the source

Copy the complete src/ directory, include src/strata.css, and import createScene from src/strata.js after the scene's HTML exists. The package is not published to npm.

import { createScene } from './src/strata.js';
const scene = createScene(document.querySelector('.scene'));
scene.setLayout('grid');
scene.focus('details');
// When removing the scene:
scene.destroy();

Scope and constraints

Strata uses flat DOM surfaces, not mesh geometry or WebGL. Rendering cost depends on content, blur, shadows, panel count and the browser. The runtime has no dependencies and makes no network requests. The demonstration site may load optional fonts. Eye tracking remains a separate research prototype.
