How to interact

Select a title or card to focus. Select it again, click the background, or press Escape to return.

Drag a header or card to arrange. On a path, drag to turn the collection and release to coast.

Resize a workspace panel from its corners. Modules adapt to the available space.

Keyboard: Tab reaches controls. Enter selects. Arrow keys on move and resize handles make precise adjustments.

Small screens use a readable stack. Your device’s reduced-motion preference is respected.

Measurements & methodology

The current runtime is 15,945 bytes gzipped across four JavaScript and CSS source files. Files are compressed individually at gzip level 9, without minification. Fonts, images, demo code and type declarations are excluded. kB = 1,000 bytes.

The controller cancels its scheduled animation frames when paused or offscreen. This does not count animations owned by your application or the browser.

The browser benchmark measures frame intervals for six lightweight HTML cards, after an idle baseline and warm-up. Results depend on your device, refresh rate, browser and content; frame intervals are not input latency.

ALPHA, WITH CLEAR LIMITS

Small core. Real constraints.

Living Space uses flat DOM surfaces in CSS 3D space. It is not a scene-geometry engine. Test your own content, browsers and devices before shipping.
