A repeatable frame cadence check

This measures animation-frame intervals for six lightweight DOM cards on a moving belt, after a 60-frame idle baseline and 30-frame warm-up. It reports 180 active frames, including the work your browser does around Living Space. Keep this tab visible and the stage in view. Run again to see variability.

This is a diagnostic, not a guarantee of device performance or an input-latency measurement. Browser load, refresh rate, power mode, panel contents, blur and capture tools affect the result. The test respects reduced motion and compact layouts; it will ask for a wider viewport if needed.

What the runtime does less of

  • Suspends its animation work when paused, offscreen, hidden, in a compact layout, or under reduced motion.
  • Uses transform-based motion on existing HTML; native inputs and application state stay in place.
  • Shares document gesture handlers per scene and caches panel references.
  • Stops collision packing when the layout converges.
  • Restores authored DOM attributes and cancels owned work when destroyed.

Budget your content too

Start with a handful of panels. Heavy video, large shadows and nested effects still cost rendering time. Use compact summaries for secondary modules, keep depth of field modest, pause inactive scenes, and test the actual UI on the slowest device you support.
