Living Space arranges real interface panels in depth. Your inputs, labels, links and content remain ordinary DOM elements.

Release status: public source alpha. The website is on GitHub Pages; no npm release is available. Copy the source or install a locally packed tarball; the package name is provisional.

1. Add the structure

Include the structural stylesheet. A scene has a camera and uniquely identified surfaces; a visual wrapper keeps blur separate from the transformed shell. The example below requires no playground styles.

<link rel="stylesheet" href="./strata/strata.css">
<div class="scene" id="scene" tabindex="-1" style="height:600px">
  <div class="camera">
    <article class="surface" data-surface="intro" data-x="-160" data-y="0">
      <div data-visual>
        <button data-focus>Introduction</button>
        <button data-drag aria-label="Move introduction">Move</button>
        <p>Native content, editable controls and links.</p>
      </div>
    </article>
    <article class="surface" data-surface="details" data-x="160" data-y="0">
      <div data-visual><button data-focus>Details</button><p>More content.</p></div>
    </article>
  </div>
</div>

Open the standalone example. Style colors, fonts and panel interiors yourself. Do not apply filters or extra transforms to the outer surface.

2. Mount and clean up

import {createScene} from './strata/strata.js';
const scene = createScene(document.querySelector('#scene'), {
  onChange: state => console.log(state.active, state.mode)
});
scene.setMode('overview');
// Before removing the element, including framework unmount:
scene.destroy();

Import is safe before a browser mount. Call createScene only in a browser, after the panels exist. The panel list is fixed for a mount; destroy and remount when it changes. Keep application data in your framework or native inputs, not in the controller.

Options

OptionDefault / purpose
onChangeOptional callback receiving state. It is a state notification, not a frame-by-frame animation ticker.
workspaceOpt into adaptive packing, resizing and assembly. Inferred from data-workspace=true or legacy data-case=creative when omitted.
compactWidth650px. Below this width the scene becomes a flat document stack.
referenceWidth1120px. Coordinate reference width for authored data-x / data-y positions.
observeVisibilitytrue. Pause offscreen activity when IntersectionObserver is available.
assemblyOptional frame width, height and slots keyed by surface ID. Slots specify x, y, width and height. The first surface is the primary canvas.

Public methods

MethodBehavior
focus(id)Select a panel. A path card travels to the front before focusing.
setMode('focus' | 'overview')Focus or return to the current arrangement.
setPath(name, options)none, belt, float, wave or spiral. Diameter 200–900, axis −80–80°, speed 0.2–3. Optional interaction: pause (default), steer or none; tilt: 0–12° (default 0). Steer reverses left, brakes centrally and advances right on belt/wave/spiral paths; vertical cursor position leans the path.
setLayout('grid' | 'pile' | 'fan' | 'rail')Rearrange the same collection without recreating its controls.
setPileDragMode('cycle' | 'free')Default cycle: releasing a pile drag tucks the card behind the stack. Free placement leaves cards on the canvas; switching back gathers them.
sendToBack()Cycle the front/selected card in a pile or fan.
navigate(step)Rail only: move by an integer number of items, clamped at the ends. Horizontal dragging scrubs the shared rail and snaps with bounded momentum. state.railIndex is the target; state.railPosition is the fractional scrub position.
setAssembled(boolean)Workspace only: composed interface or separated modules.
resizeSurface(id, width, height)Workspace only: resize within scene constraints and reflow supporting modules.
setDepth(value)Depth multiplier, 0–1.5.
setDepthOfField(pixels)Background blur strength, 0–3. Depth may multiply the resulting blur. Reading and reduced-motion safeguards still apply.
orbit(degrees)Camera yaw, −12–12°.
pause() / resume()Application-level activity control. Does not override reduced-motion, hidden-page, compact or offscreen gates.
reset()Restore authored sizes/positions, depth=1, blur strength=1.1, camera yaw=0 and primary selection; separate modules. Retain path parameters, layout, pile order and pause state.
destroy()Cancel work, detach listeners/observers and restore controller-owned DOM state. Safe to call repeatedly.

state, stats and isPaused are read-only snapshots. See the TypeScript contract for fields.

Workspace markup

Use labelled data-resize="nw|ne|sw|se" buttons as direct surface children. Wrap full controls in [data-content] and add optional [data-summary] content with a [data-summary-icon] for compact modules. Full controls give way to summaries and icon-label tiles before geometric scaling. Keep long interiors scrollable and preserve access to the full module.

const workspace = createScene(element, {
  workspace: true,
  assembly: {
    width: 1100, height: 620,
    slots: {
      intro: {x: 0, y: 0, width: 430, height: 560},
      details: {x: 380, y: -145, width: 260, height: 270}
    }
  }
});
workspace.setAssembled(true);

Run the independent adaptive workspace to inspect assembly slots, semantic content wrappers and corner buttons without demo CSS.

Interaction rules

  • Click a surface to focus; click its background or use Escape to return to overview.
  • Drag a grip or eligible card area. Native controls retain their actions. A movement threshold separates click from drag.
  • In a pile, drag/release cycles the card to the back unless free placement is enabled. On a path, dragging scrubs that path. Release velocity eases toward the normal rotation speed; panels do not detach.
  • In a workspace, corner resizing is constrained; neighbors compact, repel and recede. Reduced motion removes decorative tilt.
  • Arrow keys move a focused grip or resize corner. Native keyboard focus keeps controls reachable.

Access and compatibility

Use meaningful DOM order, labels and text. Never rely on depth alone to convey status. Compact layouts are real document stacks; reduced motion suppresses animation and blur. The runtime is dependency-free and sends no telemetry. It needs modern Pointer Events, ResizeObserver and CSS transforms; a Web Animations capable browser is needed for layout morphs.

Flat DOM panels are not a mesh renderer or a collision-accurate physics engine. Dense arbitrary layouts can still exceed available space. Test your content, nested scroll, zoom and overlays in the browsers you support. Current browser validation uses Chromium; Safari, Firefox and physical phones remain release-validation work.
